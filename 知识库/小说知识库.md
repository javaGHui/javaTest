## 🌍 世界观

### 天灾序列
1. **旱灾** - 连续数月无雨，土地龟裂，粮食绝收（卷一）
2. **瘟疫** - 悄然蔓延，从北方到全国（卷一至卷四）
3. **蝗灾** - 蝗虫过境，庄稼尽毁（卷七）
4. **洪灾** - 洪水泛滥，淹没村庄（卷七）
5. **寒潮** - 极端气候，冰雪覆盖（卷七）

### 地理格局
- **北方**: 旱灾最严重，瘟疫发源地
- **江南/南方**: 瘟疫最严重区域，后期主要活动区
- **青云山**: 苏神医寻九叶灵芝之地
- **白药谷**（西南）: 稀缺草药产地
- **甘草坡**（西北）: 基础草药产地
- **人参岭**（东北）: 人参、鹿茸等珍贵药材
- **岭南**: 热带草药产地

## 🩺 医术体系

### 能力等级
| 等级 | 描述 |
|------|------|
| 学徒 | 基础认药、简单护理 |
| 医者 | 脉诊、配药、独立诊治轻症 |
| 名医 | 诊治疑难杂症、独当一面 |
| 神医 | 领悟秘传、救治重症 |
| 终极 | 《神医心法》大成 |

### 药材等级
- 普通草药: 常见易得
- 稀缺草药: 白药、重楼、天麻
- 珍贵药材: 人参、鹿茸、灵芝
- 极致药材: 九叶灵芝（十年成熟，极寒高山）

### 疾病分类
- 轻症: 感冒、发烧、腹泻
- 中度: 需配药调理
- 重症: 高烧不退、浑身红疹
- 疑难: 痨病、变异瘟毒

### 叙事要求
- 开头: 承接上章，设置悬念/危机
- 中段: 情节展开，人物行动
- 高潮: 核心事件，矛盾冲突
- 结尾: 留下悬念，为下章铺垫

### 常用手法
- 对话推进剧情
- 场景描写渲染氛围
- 心理描写刻画人物
- 动作描写紧张激烈
- 细节描写增强代入感
